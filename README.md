# Data Quality and Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on checking data quality and performing Exploratory Data Analysis (EDA) using Python.

It helps identify missing values, duplicate records, potential outliers, and patterns in the dataset.

## 🎯 Objectives
- Check missing values in the dataset.
- Identify duplicate records.
- Analyze data using descriptive statistics.
- Detect potential outliers.
- Visualize data using graphs.
- Understand relationships between numerical variables.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## ✨ Features
1. Data Loading
2. Data Quality Checking
3. Missing Value Detection
4. Duplicate Record Detection
5. Descriptive Statistics
6. Outlier Detection using IQR
7. Data Visualization
8. Correlation Analysis
9. Export Analysis Report

Run the following command:

## 📊 Expected Results

The project generates:
- Data quality report
- Missing values chart

- Correlation heatmap

- Cleaned CSV dataset

## 📌 Conclusion

This project demonstrates how Python can be used to check data quality and perform exploratory data analysis.

It helps understand datasets, identify data-quality issues, and discover useful patterns through visualizations.
